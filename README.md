# Crystal Clicker

Кликер-игра с системой эволюций, апгрейдами и критами. Полностью на vanilla JS, без библиотек.

## 🎮 Играть

👉 [[Cerezar.github.io/crystal-clicker](https://Cerezar.github.io/crystal-clicker/)](https://Cerezar0.github.io/Crystal-Clicker/)

## ✨ Фичи

- 🖱️ Ручная добыча кристаллов
- ⚡ 4 улучшения: сила, автодобыча, CRIT-режим, благословение
- 💎 3 эволюции: Аметист, Изумруд, Рубин
- 🎯 Крит-система с floating text
- 💾 Сохранение прогресса (localStorage)
- 📱 Адаптив под мобилки и десктоп

## 🛠️ Стек

- HTML5
- CSS3 (custom properties, animations, glassmorphism)
- Vanilla JavaScript (ES6+)

## 🚀 Как сделано

Vibe-coded with Cursor / Codex.
